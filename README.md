# Arsenal of Ages

A pack-opening game: collect 420 real weapons from the Stone Age to today.

Play it at https://tylerorton246-afk.github.io/arsenal-of-ages/. Your progress saves in your browser on that device;
on a phone, add the page to your Home Screen to keep it like an app. Settings has a backup code to move your game
to another device.

This repository only holds the built game. It is generated by `node tools/site.mjs` from the game's source.
